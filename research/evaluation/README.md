# Evaluation

This directory contains evaluation design and metric implementations used by research runs.

Planned contents:

- Detection metrics (precision, recall, F1, AUROC) with confidence intervals.
- Calibration metrics (Brier score, ECE) only when a genuine calibrator exists.
- Counterfactual faithfulness and interaction estimators.
- Steering paired-evaluation analysis.
- Repair verification and regression metrics.
- Statistical tests and multiple-comparison corrections.

No benchmark numbers exist yet. Any future number must link to an exported experiment bundle and state its claim kind, sample size, seed, model/SAE hashes, and limitations.
